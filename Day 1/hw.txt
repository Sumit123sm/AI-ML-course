### Q5. Operator Precedence Evaluation

Evaluate and explain the expression: `x = 10 + 3 * 2**2`.

* **Output value:** `22`

**Explanation:**
Python follows standard mathematical operator precedence rules (PEMDAS/BODMAS):

1. **Exponentiation (`**`)** is evaluated first: `2**2 = 4`
2. **Multiplication (`*`)** is evaluated next: `3 * 4 = 12`
3. **Addition (`+`)** is evaluated last: `10 + 12 = 22`

### Q6. Swap Two Numbers

Write a program to swap values of two numbers entered by the user.

```python
a = input("Enter first number: ")
b = input("Enter second number: ")

print(f"Before swapping: a = {a}, b = {b}")

# Swapping using Python tuple unpacking
a, b = b, a

print(f"After swapping: a = {a}, b = {b}")

```

### Q7. Celsius to Fahrenheit Conversion

Convert a temperature from Celsius (string input) to Fahrenheit.
Formula: `FahrenheitTemp = (CelsiusTemp * (9 / 5)) + 32`

```python
celsius_str = input("Enter temperature in Celsius: ")
celsius_temp = float(celsius_str)

fahrenheit_temp = (celsius_temp * (9 / 5)) + 32
print(f"Temperature in Fahrenheit: {fahrenheit_temp}")

```

### Q8. Area of a Circle

Take the radius as user input and print the area.
Formula: `Area = Pi * r**2` (where `Pi = 3.14`)

```python
r = float(input("Enter the radius of the circle: "))
pi = 3.14

area = pi * (r ** 2)
print(f"The area of the circle is: {area}")

```

### Q10. Integer and Fractional Parts

Take a decimal number as input and output its integer and fractional parts.

```python
num = float(input("Enter a decimal number (e.g., 45.78): "))

int_part = int(num)
frac_part = num - int_part

print(f"Integer part: {int_part}")
# Using round to avoid floating-point representation artifacts (e.g., 0.77999999999)
print(f"Fractional part: {round(frac_part, 2)}")

```
